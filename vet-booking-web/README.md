# VetBooking Frontend

A modern, responsive frontend application for the Veterinary Management System, built with **React**, **Vite**, and **TypeScript**. This client interfaces with the .NET 10 Clean Architecture backend API to manage owners, pets, appointments, and vet schedules.

---

## 🛠️ Tech Stack

- **Framework:** React (v19+)
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** _(Tailwind CSS / CSS Modules)_
- **HTTP Client:** Fetch API / Axios

---

## 📋 Prerequisites

Before you begin, ensure you have the following installed on your machine:

- **Node.js** (LTS version recommended, v18 or higher)
- **npm** (comes with Node.js) or **pnpm** / **yarn**
